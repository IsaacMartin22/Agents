# Agents

This repository is a sandbox for building and orchestrating agents that are useful for software development workflows.

## Initial Agent

### Documentation Agent

The first agent in this repo focuses on pull request documentation quality.

It takes an existing PR, reviews the code changes, and suggests or drafts any missing documentation updates, such as:

- `README.md` updates
- `index.html` updates

See `agents/documentation-agent.md` for the agent definition and workflow.
